# Coleta de Conhecimento — ATS Informática

Este material serve pra registrar, de forma organizada, o que você sabe sobre os módulos e rotinas do sistema. Não precisa escrever nada manualmente — é tudo feito em conversa com o Claude Code.

## Como abrir

1. Instale o Claude Code (se ainda não tiver): peça ajuda ao time de TI se precisar.
2. Abra o terminal **dentro desta pasta** (`kb-analista`).
3. Digite `claude` para iniciar.
4. Digite `/entrevista-rotinas` (ou apenas escreva "vamos começar").

## Como funciona

O Claude vai te perguntar, um de cada vez:
1. Quais módulos do sistema existem hoje (ele já tem uma lista de partida — você só confirma, corrige ou completa).
2. Para cada módulo confirmado, quais rotinas ele tem (de novo, já tem uma lista pré-carregada pra você validar).
3. Para cada rotina: o que é, quem usa, como usar passo a passo, erros comuns, e com quais outras rotinas/módulos ela se relaciona.

Você pode parar a qualquer momento — é só avisar ("por hoje é só", "vamos parar aqui"). Da próxima vez que abrir e digitar `/entrevista-rotinas`, ele continua exatamente de onde parou.

## Visualizando o progresso

Esta pasta é compatível com [Obsidian](https://obsidian.md/). Se quiser acompanhar visualmente (grafo de relações entre rotinas e módulos), abra a pasta `wiki/` como um "vault" no Obsidian.

## Quando terminar

Devolva esta pasta inteira (`kb-analista`) pra equipe — o conteúdo será integrado na base de conhecimento principal.
