## O que é
O **Busca Menu** é uma ferramenta de busca disponível em qualquer módulo do sistema. Permite ao usuário digitar o nome (ou parte do nome) de uma rotina para localizá-la, sem precisar saber em qual menu (Cadastros, Movimentos, Relatórios, Utilitários, etc.) ela está.

## Como usar
Digite o nome da rotina desejada no campo de Busca Menu, disponível na barra de ferramentas principal do sistema.

> [!NOTE]
> A rotina só aparece na busca se o sistema estiver configurado para trabalhar com ela **e** o usuário logado tiver permissão de acesso a ela.

## Quando usar
Sempre que o usuário não souber em qual menu uma rotina específica está localizada.
